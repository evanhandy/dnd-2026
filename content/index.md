# Welcome

This is a wiki/knowledge base/whatever for planning, tracking, and running my upcoming TTRPG campaign. It uses [Obsidian](https://obsidian.md/) for creating and managing its content and [Quartz](https://quartz.jzhao.xyz/) for uploading it to the internet.

My hope is that this can be a home for [[World Lore/index|World Lore]] and [[Campaign Notes/index|Campaign Notes]] that can be updated and readily accessible throughout the campaign. It's got a search bar! It's got per-page table of contents! [Backlinks](https://obsidian.md/help/plugins/backlinks) are listed for each page too!

> [!TIP] Links
> Throughout this wiki you'll see many [[Why I Like Obsidian|links]]. They go to other notes (or occasionally external websites) so that world lore and other information can be gently delivered in a (hopefully) fun-to-explore format.
